## 🔎 진행 방식
> 형식은 중요하지 않아요. 분량도 중요하지 않아요.<br>
> 의미없이 요약 정리하지 말아요!<br>
> 꼭 생각을 많이 하면서 읽어봐요. 그리고 그 생각을 같이 공유해요 :)

- 세션 전: 전원 개인 정리본 작성 후 공유 (md > pr)
  - 핵심 요약 (3~5줄)
  - 인상 깊었던 / 동의 안 되는 내용
  - 우리 프로젝트에 적용한다면?
  - `등 자유롭게 본인의 생각을 정리`
- 세션 중: 발표 또는 라운드 공유(소규모)+ 토론
- 세션 후: 서기가 논의 내용 기록 or RTT 사용 (매 장마다 로테이션)
